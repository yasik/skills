# TypeScript Code Style

These pages hold the TypeScript conventions. Use the repository's package
boundaries, runtime, and test runner. For new packages, prefer explicit public
exports, `.ts` files for non-UI logic, and package-local tests.

Read the page that matches the work you are doing; the target repository's own
instructions take precedence.

## Pages

1. [Conventions](./conventions.md): general style, destructuring, imports and
   exports, variables, control flow, helper placement, comments, and protocol
   code.
2. [Testing and tooling](./testing-and-tooling.md): test approach, type
   checking, formatting, lint rules, and the commands that gate a
   change.
